# `electromagnetic_induction`

For a coil in a uniform field, `Φ = B_n A cos θ` and `ε = −N dΦ/dt`. This
fixture varies the signed normal field component `B_n` linearly, so
`ε = −N A cos θ (dB_n/dt)` and the sign carries Lenz's law. `θ` is measured
from the coil normal and `N` is a positive integer. The renderer shows flux,
field, and induced emf as timeseries.
